
# 微软拼音卡输入法解决器&VPN网络修复

按 Win+Space（可自定义快捷键）切换微软拼音输入法的中英文模式。

- 因为微软自带的微软拼音输入法切换中英文的快捷键是ctrl加空格，而且不能改动到别的更不常用的快捷键，容易与apex，mc之类的游戏产生冲突，这个软件是用于给不想额外添加一个美式键盘输入法的用户使用的，

- 理论上来说因为日语韩语用的都是同一个ImmSetConversionStatus，所以应该也能用。但是我没测试过。

- 理論的には、日語と韓語は同じ【ImmSetConversionStatus】を使っているから、多分使えるはずだね。でも、試したことはない

- 이론적으로는 일본어랑 한국어가 같은 【ImmSetConversionStatus】를 쓰니까 아마 쓸 수 있을 거야. 근데 난 테스트는 안 해봤어

附带代理修复等扩展模块

- 如果开着代理软件关机的时候重新启动电脑，有概率因为代理遗留进程导致无法联网。这个软件开机自启动的时候会清除遗留进程。

## 功能
- 全局快捷键切换微软拼音中英文，默认 Win+Space
- 代理修复：解决第三方 VPN 异常退出后残留代理导致的断网


## 使用
1. 解压 zip，双击其中的 WinSpaceImeToggle.exe 即可运行。
2. 删除运行目录 modules 中不需要的模块 DLL，重启程序即可移除对应功能与设置分页。






<details>
<summary>多语言</summary>


界面文本全部由Languages目录中的语言文件提供（INI 键值对，文件名即语言代码，如zh-CN.ini、en.ini）。
每个语言文件内置meta.nativeName键，作为“界面语言”下拉框中的语言显示名；文件内的键（如app.title、ime.name）与源码一一对应，值为该语言下的文本，支持{0}占位符。

新增语言只需三步：
1. 在 Languages 目录新建 <语言代码>.ini（如 ja.ini）；
2. 参照 en.ini 填写全部键的翻译（缺失的键会自动回退英文）；
3. 重新构建或直接复制新文件到运行目录 Languages\，打开设置即可在“界面语言”下拉框中选择。

模块文本同样来自语言文件：模块通过 ModuleContext.T("key") / TF("key", ...) 读取，主程序通过 Localization.T("key") 读取；键未命中时自动回退英文，再未命中则显示键名本身。
不过呢，由于ImmSetConversionStatus这个功能只适用于东亚语言的切换，提供的日语和韩语就覆盖大部分了，也没人有必要做多语言吧

</details>


<details>
<summary>注意事项</summary>


- 程序默认以普通权限运行；对管理员权限窗口（UAC 界面、部分游戏/IDE）的按键事件，低级钩子收不到。
- 自定义快捷键时请避免与系统快捷键冲突（如 Win+E、Ctrl+Space 等）。
- 若组合键包含 Shift，注意微软拼音自带"按 Shift 切换中英"功能，可能与本工具行为叠加。



</details>
